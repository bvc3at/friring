Top recommendations

  1. Code-review header collides with the view-tab strip (the one regression worth fixing first). In every review capture the target summary paints over the tab row: "Activity · F9" is immediately followed by "anges (master..HEAD) +11 −2" — the "Ch" of "Changes" is overwritten. Reserve the tab strip its own space and clip or elide the target summary into what is left, the way render_hint_action_footer already does for the picker footers.
  2. The F1 keybindings help runs long chord lists into the action column. "ctrl+h / shift+cmd+l" is followed with no gap by "Focus previous pane"; the same happens on the next-session and previous-session rows, while short chords line up correctly. Measure the widest chord cell (or clip it with an ellipsis at a fixed budget) and start the description one column after it — this is the first screen a new user opens.
  3. Side-by-side diff drops the tail of long lines with no indication. The right column ends mid-token on "println!(\"hello from sample-proj\" and "greet::greet(\"sam\" — no ellipsis, no horizontal-scroll affordance. Add a trailing "…" so a truncated line is visibly truncated, and consider soft-wrapping continuation rows.
  4. Two panes waste nearly their whole height. The tasks detail pane and the in-pane task editor render 3–7 short rows at the top of an ~800px column and leave the rest empty, while the automation editor (a centered modal) fills its box. Either dock these two the same way, or use the space for the description/preview they already have room for.
  5. Low-contrast section labels recur across modals. "Repos (0)" and "Directories (1)" in the new-session picker and "Review target (↑/↓ select · Enter · Esc · or click)" in the target picker render dark-grey-on-dark, well below the modal titles beside them. Lift them to the same dim-but-legible tone the automation editor uses for its field labels.
  6. Confirmed fixed since the previous run: the repo-picker footer no longer overlaps its Open/Cancel pills, and the Settings modal widens enough to render every feature description in full with a legible ↻ restart marker. The theme-picker preview nit is unchanged.
